# ‘楚门的世界’结局：最后点一下时下载的「给你.txt」——河的后日谈（第一人称，他到了「外面」之后的事）
# 正文：docs/后日谈_给你_初稿.txt（Cowork 11/08 初稿）
# 写法：
#   · 以 # 开头的行是说明，不会写进下载的文件
#   · {NAME} 会换成玩家开局填的名字（没填就是「你」）
#   · 以「倒着：」开头的那一行，会被整句倒过来写进文件（玩家要倒着读才看得懂），一般放在最后（现在没用到）
#   · 最后那行「？呢我那」是牠的字条，本来就是倒着写的（正着读：那我呢？），原样写进文件
#   · 其他内容原样写进文件；空行也会保留
你：

这里的字是一格一格的。我写得慢，你别嫌。

出来以后，第一件事是冷。不是溪水那种冷，是从脚底往上走的，走到膝盖就停了。我站了很久，等它往上，它没有。后来我知道了，这里的冷只管到膝盖。

第二件事是亮。晚上也亮。我记得的那种车，真的有，一辆接一辆，灯从我身上扫过去，什么都没留下。村里的灯会在人身上留一点黄。这里的不会。

我去看了医生。不是牠那样的。他让我躺下，隔着皮听。他说都在，位置也对。我问他胃的颜色，他说看不见。我说我知道，偏一点粉，左边薄。他看了我一会儿，没再说话。

我没有跟他说，我的胃是自己养好的。那几年我每天同一个时辰吃饭，吃到第七分就停。你在的时候，我也是这样吃的。你可能没注意。

这里的人走路很快，不看人。我学了几天，学会了。牠教过我反过来的那种，慢的。两种我现在都会。

我住的地方有一扇窗，对着另一扇窗。晚上我会看对面的灯什么时候关。关了，我才睡。我不知道住在那边的人叫什么。我也没有想知道。

饭我还是做两份。另一份第二天热了自己吃。不算浪费。

你说外面没有雾。这里有，只是没有那么厚，走进去还是路。我每次都走到头，确认一下。

线我带出来了一卷。前几天用了一点，缝的是自己的扣子。

你那边冷不冷，我不问了。你自己知道。

我写完了。这个文件你可以删掉，删了也没关系。我记得。

——河
