# 正文：docs/后日谈_给你_新稿_1110.txt（Cora 11/10 改定）
# 写法：
#   · 以 # 开头的行是说明，不会写进下载的文件
#   · {NAME} 会换成玩家开局填的名字（没填就是「你」）
#   · 以「倒着：」开头的那一行，会被整句倒过来写进文件（玩家要倒着读才看得懂），一般放在最后（现在没用到）
#   · 最后那行「？呢我那」是牠的字条，本来就是倒着写的（正着读：那我呢？），原样写进文件
#   · 其他内容原样写进文件；空行也会保留
你：

这里的字是要一格一格打的。打错了要删掉，我试了很多回。

我只记得出来的那天很冷。但到膝盖就不再往上冷了。

这里晚上也很亮。车我见着了，和我记得的一样，就是太多了。灯从人身上扫过去，什么也不留。不像村里的灯照久了，衣服上会有一点黄。

我听你的话去看了医生。他让我躺着，隔着衣服听，说都在，位置也对。我问他胃是什么颜色，他说这个看不见。我说偏粉，左边薄一点。他就不说话了，低头写东西。

来到这里我也有好好对我的胃。每天一个时辰吃，吃七分。你在的时候我也这样……但你没看出来。

这里的人走得快，不看人。我跟着走了几天，学会了。牠教的那种慢的，我也还会。

我屋子的窗对着别人家的窗。那边灯灭了，我再睡。住的是谁，我不知道。

饭还是做两份。

这里也有雾，薄。不过，走进去路还是路。我每次都忍不住走到头，再回头看一眼。

线我带出来了一卷。前几天我给自己的衬衫缝了个扣子。

写完了。这个你删了也行。

——河
